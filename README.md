# WeatherMaster iOS Prototype

This repository contains a first-pass SwiftUI prototype for a privacy-focused iOS weather app inspired by the Android WeatherMaster app.

## Included features
- Current weather for a searched city
- Manual refresh and reload behavior
- Clean weather dashboard UI
- Simple secure-by-default design (no embedded secrets or API keys required)
- Widget-ready weather model structure

## Data source
The app uses the free Open-Meteo API, which does not require a paid API key for basic weather data.

## Run it
1. Open the project in Xcode.
2. Select the iPhone simulator or a connected iPhone.
3. Press Run.
4. Search for a city such as London, New York, Tokyo, or Berlin.

## Notes
This is a prototype only. It intentionally keeps the feature set small so it can be used quickly and debugged in real life.
